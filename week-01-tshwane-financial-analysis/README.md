Week 1: City of Tshwane Financial Performance Analysis (2024/25)

Project Overview
This project analyses the financial performance of the City of Tshwane for the 2024/25 financial year using publicly available municipal financial data from National Treasury Municipal Money.

 Objective
To examine municipal revenue, expenditure, operating surplus and capital transfers, and identify financial observations and recommendations.

 Tools Used
- Microsoft Excel

 Data Source
- National Treasury Municipal Money

 Skills Demonstrated
- Data cleaning and preparation
- Excel formulas (SUMIF)
- Financial performance analysis
- Chart creation
- Financial interpretation
- Management recommendations

 Key Findings
- Total revenue: R51.44 billion
- Total expenditure: R51.12 billion
- Operating surplus before capital transfers: R318.51 million
- Operating surplus margin: approximately 0.62%
- Capital transfers: R1.95 billion
- Surplus after capital transfers: R2.27 billion

 Recommendations
1. Strengthen revenue collection and follow-up on overdue accounts.
2. Monitor electricity procurement and employee-related expenditure.
3. Compare actual expenditure against budgets regularly.

 Conclusion
The municipality generated an operating surplus before capital transfers, but the narrow operating surplus margin indicates limited room to absorb financial pressures. Revenue collection, expenditure monitoring and regular financial review remain important.

This project was completed as part of my hands-on accounting and financial analysis portfolio development.
